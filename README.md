# Twilight HD Features

Created by **William**.

Bring features from **The Legend of Zelda: Twilight Princess HD** to **Dusklight**, including the Ghost Lantern, all 50 stamps, an HD-inspired HUD, and a Horse Flute shortcut.

## Download

Download **`twilight_hd_features.dusk`** from the [Releases page](https://github.com/williamcoelho1808/twilight-hd-features/releases).

**No compilation or Visual Studio installation is required.**

## Installation

1. Download `twilight_hd_features.dusk`.
2. Place it in your Dusklight `mods` folder.
3. Launch Dusklight and enable **Twilight HD Features**.

When updating, replace the previous `.dusk` file. Remove older standalone copies of these features and the separate Twilight HD HUD mod to avoid duplicate modifications.

## Features

### Ghost Lantern

- Receive the Ghost Lantern from Jovani after collecting 20 Poe Souls.
- Preserves his original Fairy Tears reward and dialogue.
- Includes an item acquisition sequence, a 3D model, an inventory icon, and the ability to equip and put away the lantern.
- The lantern glows more strongly as you approach a nearby Poe.
- An optional animated lantern indicator at the top of the screen signals nearby Poes.
- Detection distances can be adjusted in the mod settings.
- Dungeon detection is restricted to the current room.

### Stamps

- Collect all **50 stamps** in their corresponding HD locations.
- View your collection in a stamp album accessible from the Collection screen.
- Collected stamps and album progress are saved.

### Horse Flute shortcut

Select the Horse Flute in the inventory and press **LT** to call Epona without equipping it.

Requires owning the Horse Flute and being in a location where Epona can normally be called.

### HD HUD and menus

- Includes an adapted version of **Twilight HD HUD** by **Hyrule Hysteria**.
- HD-inspired HUD and Collection screen.
- Separate settings for minimap size and minimap marker size.
- Supports Collection screen equipment changes introduced by Twilight Essentials.

## Settings

Open the mod settings to customize the HUD, minimap, and Poe detection features.

- Enable or disable the on-screen Poe indicator.
- Adjust the indicator's detection distance.
- Adjust when the equipped Ghost Lantern starts glowing and reaches maximum brightness.
- Adjust minimap and marker sizes independently.

## Compatibility

Tested with **Dusklight 2.0.3 on Windows**.

Twilight Essentials Collection screen compatibility is included. Other mods that modify the same HUD, menus, items, or rewards may conflict.
